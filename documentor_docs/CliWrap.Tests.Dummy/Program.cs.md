# Technical Documentation: `CliWrap.Tests.Dummy/Program.cs`

## Overview

The `CliWrap.Tests.Dummy/Program.cs` file serves as the main entry point for a mock/dummy command-line executable (`CliWrap.Tests.Dummy`). This dummy application is used internally by the `CliWrap` test suite to simulate command-line interactions and verify process execution, output handling, and exit code behaviors.

---

## Assembly Attributes

* **`[assembly: ExcludeFromCodeCoverage]`**  
  Excludes the entire `CliWrap.Tests.Dummy` assembly from code coverage metrics, ensuring that test helper code does not artificially alter the coverage reports of the primary codebase.

---

## Class: `CliWrap.Tests.Dummy.Program`

* **Type**: `public static class`
* **Namespace**: `CliWrap.Tests.Dummy`

`Program` is the static entry class containing the executable path property and the application entry point logic.

---

### Static Properties

#### `FilePath`
```csharp
public static string FilePath { get; }
```
* **Type**: `string`
* **Purpose**: Provides a dynamic, cross-platform path to the compiled executable output (apphost).
* **Behavior**:
  * Retrieves the location of the currently executing assembly using `Assembly.GetExecutingAssembly().Location`.
  * Adjusts the file extension using `Path.ChangeExtension(...)`:
    * Appends `.exe` if running on Windows (`OperatingSystem.IsWindows()`).
    * Removes/omits `.exe` extension (sets extension to `null`) on non-Windows operating systems.

### Static Methods

#### `Main`
```csharp
public static async Task<int> Main(string[] args)
```
* **Type**: `async Task<int>`
* **Parameters**: 
  * `args` (`string[]`): Command-line arguments passed to the executable upon invocation.
* **Returns**: `Task<int>` – Returns an integer representing the exit code generated by the executed command.

#### Execution Logic inside `Main`:

1. **Environment Configuration**:
   ```csharp
   Environment.SetEnvironmentVariable(
       "DOTNET_SYSTEM_CONSOLE_ALLOW_ANSI_COLOR_REDIRECTION",
       "false"
   );
   ```
   Sets the `DOTNET_SYSTEM_CONSOLE_ALLOW_ANSI_COLOR_REDIRECTION` environment variable to `"false"`. This ensures that console output does not produce ANSI color codes, preventing formatting characters from interfering with string comparison assertions in tests.

2. **CLI Command Discovery & Execution**:
   ```csharp
   return await new CommandLineApplicationBuilder()
       .AddCommandsFromThisAssembly()
       .Build()
       .RunAsync(args);
   ```
   Uses the `CliFx` framework to build and run the console application:
   * **`CommandLineApplicationBuilder()`**: Initializes a new CLI application builder.
   * **`.AddCommandsFromThisAssembly()`**: Automatically discovers and registers all `CliFx` command classes defined within the `CliWrap.Tests.Dummy` assembly.
   * **`.Build()`**: Assembles the CLI application instance.
   * **`.RunAsync(args)`**: Processes `args`, executes the matching command asynchronously, and returns the exit code integer.
